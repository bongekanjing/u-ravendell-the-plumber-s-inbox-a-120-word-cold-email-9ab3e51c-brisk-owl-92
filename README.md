## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 src/main.py
```

`src/main.py` writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
See [main.py](src/main.py) for the text.
